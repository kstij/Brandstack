The Brandstack API is a read-only REST interface that lets you extract your unified commerce data for use in BI tools, data warehouses, or internal applications. It returns JSON over HTTPS so you can build integrations quickly without writing export scripts.

To get started, request an API key from **Settings \> Developer** in your Brandstack dashboard. Once you have a key, every request to `https://api.brandstack.com/v1` requires it in the `Authorization` header. The API is read-only at launch, so you can pull data but not modify it.

## What you can do

- Pull orders, customers, products, shipments, and ad spend into your warehouse.
- Query aggregated metrics with time-range filtering.
- Power internal dashboards or reporting tools.
- Automate data syncs on your own schedule.

## Base URL

```text
https://api.brandstack.com/v1
```

All endpoints shown in this documentation are relative to this base URL.

## Quick example

```bash Request
GET https://api.brandstack.com/v1/orders
Authorization: Bearer <your_api_key>
```

```json Response
truncated
{
  "data": [
    {
      "id": "ord_12345",
      "status": "shipped",
      "total": 149.99,
      "created_at": "2024-01-15T09:23:11Z"
    }
  ]
}
```
