This page lists the core read endpoints available in the Brandstack API. Every endpoint returns JSON and requires Bearer authentication. All paths are relative to `https://api.brandstack.com/v1`.

## GET /orders

Retrieve a list of orders.

```bash curl example
curl -X GET https://api.brandstack.com/v1/orders \
  -H "Authorization: Bearer <token>"
```

```json Response (truncated)
{
  "data": [
    {
      "id": "ord_12345",
      "status": "shipped",
      "total": 149.99,
      "created_at": "2024-01-15T09:23:11Z"
    }
  ],
  "pagination": {
    "next_cursor": "abcd1234"
  }
}
```

## GET /orders/{id}

## GET /metrics

Query aggregated metrics with time-range filtering.

### Query parameters

| Parameter | Type | Description |
| --- | --- | --- |
| metric | string | Metric to aggregate (e.g., revenue) |
| dimension | string | Grouping dimension (e.g., channel) |
| from | string | Start date in ISO 8601 format |
| to | string | End date in ISO 8601 format |

<CodeGroup>

```bash curl example
curl -X GET "https://api.brandstack.com/v1/metrics?metric=revenue&dimension=channel&from=2024-01-01&to=2024-01-31" \
  -H "Authorization: Bearer <token>"
```

```python Python requests example
import requests

headers = {"Authorization": "Bearer <token>"}
params = {
    "metric": "revenue",
    "dimension": "channel",
    "from": "2024-01-01",
    "to": "2024-01-31"
}
response = requests.get(
    "https://api.brandstack.com/v1/metrics",
    headers=headers,
    params=params
)
print(response.json())
```
